# 帽子が長すぎます、シェフ！

**遊ぶ → https://sakusi1508.github.io/chef-too-tall/**

長すぎるコック帽で厨房を荒らしながら料理する、60秒のモバイルブラウザゲーム。

## 操作とルール
- 指を置いて上下左右に滑らせるとシェフが動きます。厨房でも画面下の操作エリアでも操作できます。
- 帽子の先をすばやく振って野菜に当てると刻めます。刻まれた野菜は近い鍋へ移動し、自動で料理になります。
- 鍋の隣にできた皿を帽子の先で打つと、客席へ飛びます。客席のカウンターに届けば売上に加算。
- 端に飛ばすと皿が割れ、棚や換気扇に帽子をぶつけると厨房被害が増えます。失敗しても60秒は続きます。
- 30秒で店長が帽子をさらに長くします。
- 右上で一時停止、別アプリ・タブへの切替でも自動停止。
- PCはマウスドラッグまたはWASD/矢印、Enter、Pに対応。

## 保存・配布
最高売上はブラウザ内のlocalStorageに保存。ログインやスコアサーバはありません。
前作「ほうきがでかすぎます！」とは別の保存キーを使います。
HTML/CSS/JavaScript・Canvasだけで動きます。外部ライブラリやUnreal Engineは使用していません。
GitHub Pages: main / (root)。キャラクター・背景は仮の2D描画。音声・効果音は未実装。
