# 帽子が長すぎます、シェフ！

60秒のモバイル向け配膳ゲーム。長い帽子は邪魔なだけです。

https://sakusi1508.github.io/chef-too-tall/

左下で料理を受け取り、右上の配膳口へ運びます。指を滑らせて移動し、帽子は進行方向の後ろへゆっくり向きを変えます。棚や壁につかえたら少し戻り、広い場所で向きを変えてください。帽子も棚・壁との衝突判定があり、引っかかったまま通り抜けられません。

狭い近道と広い外周ルートがあります。料理は自動で受け渡し、失敗でゲームオーバーにはなりません。矢印・WASDにも対応。一時停止・同じ厨房で再挑戦ができます。

最高売上は端末のブラウザに保存します。以前の帽子で調理する版とは記録を分けています。外部通信・外部素材・ライブラリは不要。
